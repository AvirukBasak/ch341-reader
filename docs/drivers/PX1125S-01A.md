# SkyTraQ PX1125S-01A

Driver name: `phoenix` (loaded from `drivers/PX1125S01A.py`)

## Overview

The GNSS receiver module has 3 layers in general:

1. **The Antenna** - the large ceramic patch antenna (possibly)
2. **SkyTraQ PX1125S-01A Chip** - a.k.a "phoenix", processes the GNSS signals, produces NMEA sentences, communicates via UART.
3. **CH340C UART-USB** - takes NMEA from the MCU and exposes a USB interface for a PC

- The chip has its own binary protocol, see [AN0037 - Binary Messages of SkyTraQ Phoenix GNSS Receiver](https://www.skytraq.com.tw/homesite/AN0037.pdf).
- You can send these commands over USB, going via the CH340C chip.
- This program handles the framing for you.

## ACK / NACK

After pressing Ctrl+C to stop the read loop following a `write`, the driver reports whether the command was acknowledged:

A successful `ACK` echoes back the command ID:
```
[INFO] PX1125S01A.py: ACK (83): 83 64 02
```

A `NACK` looks the same but with a leading `84` byte:
```
[INFO] PX1125S01A.py: NACK (84): 84 64 02
```

## Text Commands (`$...`)

A higher-level, human-readable alternative to raw hex payloads. The driver parses these and converts them to the appropriate binary payload automatically.

As usual, you cannot use spaces in these commands, which is why they are delimited with commas or `=`.

All text commands begin with `$` and use `txt phoenix` as the write mode and template. Text commands are case-insensitive.

---

### Restart

```shell
write $Restart txt phoenix
```

Equivalent to `write 01 hex phoenix`.

---

### Query Active Constellations

```shell
write $Get-Active-Constellations txt phoenix
```

Equivalent to `write 64_1a hex phoenix`.

---

### Query NMEA Sentence Intervals

```shell
write $Get-Msg-Intervals txt phoenix
```

Equivalent to `write 64_03 hex phoenix`.

---

### Set Active Constellations

```shell
write $Set-Active-Constellations:GP=1,GL=0,GA=1,GB=1,GI=1,W=1 txt phoenix
```

Key-value pairs (order irrelevant), omitted constellations default to `0`:

| Key | Description         | Values  |
|-----|---------------------|---------|
| `GP` | GPS               | `0` / `1` |
| `GL` | GLONASS           | `0` / `1` |
| `GA` | Galileo           | `0` / `1` |
| `GB` | BeiDou            | `0` / `1` |
| `GI` | NavIC             | `0` / `1` |
| `W`  | Write to FLASH    | `0` / `1` |

Equivalent to `write 64_8C_<B2>_<B3>_<W> hex phoenix`.

---

### Set NMEA Sentence Intervals

```shell
write $Set-Msg-Intervals:GGA=1,GSA=1,GSV=1,GLL=1,RMC=1,VTG=1,ZDA=1,GNS=0,GBS=0,GSR=0,DTM=0,GST=1,W=1 txt phoenix
```

Key-value pairs (order irrelevant), omitted sentences default to `0` (disabled):

| Key   | Description                              | Values (seconds) |
|-------|------------------------------------------|------------------|
| `GGA` | Fix data                                 | `0`–`255`        |
| `GSA` | DOP and active satellites                | `0`–`255`        |
| `GSV` | Satellites in view                       | `0`–`255`        |
| `GLL` | Geographic position                      | `0`–`255`        |
| `RMC` | Recommended minimum data                 | `0`–`255`        |
| `VTG` | Course and speed over ground             | `0`–`255`        |
| `ZDA` | Date and time                            | `0`–`255`        |
| `GNS` | Fix data (multi-constellation)           | `0`–`255`        |
| `GBS` | GNSS satellite fault detection           | `0`–`255`        |
| `GSR` | GNSS range residuals                     | `0`–`255`        |
| `DTM` | Datum reference                          | `0`–`255`        |
| `GST` | Position error statistics                | `0`–`255`        |
| `W`   | Write to FLASH                           | `0` / `1`        |

A value of `0` disables that sentence type. Any non-zero value is the interval in seconds.

Equivalent to `write 64_81_<GGA>_<GSA>_..._<GST>_<W> hex phoenix`.

## Binary Commands

All commands use `hex phoenix` as the write mode and template.

---

### Reset (`01`)

Restarts the chip. The firmware version banner appears on reboot.

```shell
write 01 hex phoenix
```

Output:
```
$SkyTraq 3.0.1
```

---

### Query NMEA Sentence Intervals (`64 03`)

Returns the current output interval (in seconds) for each NMEA sentence type.

```shell
write 64_03 hex phoenix
```

Output:
```
[INFO] PX1125S01A.py: Sentence Intervals (Sec): GGA:1 GSA:1 GSV:3 GLL:1 RMC:1 VTG:1 ZDA:1 GNS:0 GBS:0 GSR:0 DTM:0 GST:1
[INFO] PX1125S01A.py:          Payload (Bytes): 64 81 01 01 03 01 01 01 01 00 00 00 00 01
```

---

### Set NMEA Sentence Intervals (`64 02`)

- Sets the output interval for each NMEA sentence type.
- Payload byte order matches the query response above: `GGA GSA GSV GLL RMC VTG ZDA GNS GBS GSR DTM GST`.
- A value of `0` disables that sentence type.
- Any non-zero value is the interval in seconds.

The last byte controls persistence:
- `00` - ephemeral (lost on power cycle)
- `01` - persistent (written to FLASH)

**Example:**

This example does the following:
- Sets `GSV` sentences from 3 seconds to 1 second intervals
- Enables `GST` sentences at 1 second intervals
- Writes the config to internal FLASH fr persistence

```shell
# Persistent (written to FLASH), last byte 01
write 64_02_01_01_01_01_01_01_01_00_00_00_00_01_01 hex phoenix
```

- `GSV` reports position of satellite in the sky and signal strength (C/N0).
- By default it's set to 3 seconds but we are setting it to 1 second
- `GST` reports the standard deviation of latitude, longitude, and altitude directly from receiver.
- Without `GST` we would need to estimate position errors instead.

The following is the same except it is ephemeral: the last byte is `00`.

```shell
# Ephemeral (lost on power cycle), last byte 00
write 64_02_01_01_01_01_01_01_01_00_00_00_00_01_00 hex phoenix
```

---

### Query Active Constellations (`64 1a`)

Returns which GNSS constellations are currently enabled.

```shell
write 64_1a hex phoenix
```

Output:
```
[INFO] PX1125S01A.py: Constellations (Bool): GP:True GL:False GA:True GB:True GI:True
[INFO] PX1125S01A.py:       Payload (Bytes): 64 8c 00 1d
```

Constellation codes:
- `GP` = GPS
- `GL` = GLONASS
- `GA` = Galileo
- `GB` = BeiDou
- `GI` = NavIC
